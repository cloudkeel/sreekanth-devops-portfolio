## Site

Static HTML, CSS and JavaScript with relative assets. No build step or application backend is required. GitHub Pages publishes the root of the `main` branch; `.nojekyll` disables Jekyll processing.

Edit `index.html` for content, `styles.css` for layout and `script.js` for the project-brief copy interaction. Changes pushed to `main` trigger publication.

## Search visibility

The page includes a canonical URL, a freelance DevOps title and description,
Open Graph and Twitter preview metadata, and ProfilePage/Person JSON-LD using
public, visible profile details. Keep metadata and structured data consistent
with the visible content. Do not add private employer or product information.

`sitemap.xml` lists the single canonical page. Section anchors are not separate
pages. After publication, verify a URL-prefix property for
`https://cloudkeel.github.io/sreekanth-devops-portfolio/` in Google Search Console,
submit `sitemap.xml`, and inspect/request indexing of the canonical page. Add a
verification file or meta tag only when Google provides the actual value.

This is a GitHub Pages project site. Crawlers read robots.txt at the host root,
`https://cloudkeel.github.io/robots.txt`; a file in this project's subdirectory
would not control crawling. The root returned 404 and the live page had no
X-Robots-Tag restriction when checked on 19 October 2026. No indexing or ranking
claim is implied. Search Console submission and Google's rich-results validation
remain post-publication checks.
