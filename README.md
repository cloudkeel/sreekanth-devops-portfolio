# Sreekanth Lingaladinne — Personal Portfolio

DevOps Architect portfolio covering cloud infrastructure, Kubernetes, CI/CD, infrastructure as code, FinOps, freelance engagements and professional experience.

Live site: https://cloudkeel.github.io/sreekanth-devops-portfolio/

## Site

Static HTML, CSS and JavaScript with relative assets. No build step or application backend is required. GitHub Pages publishes the root of the `main` branch; `.nojekyll` disables Jekyll processing.

Edit `index.html` for content, `styles.css` for layout and `script.js` for the project-brief copy interaction. Changes pushed to `main` trigger publication.
